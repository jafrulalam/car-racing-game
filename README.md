ROAD RUSH 3D — 1V1 RACING + SOUND

HOW TO RUN
1. Extract Road_Rush_3D_1v1_Upgrade.zip.
2. Open the extracted folder in VS Code.
3. Use VS Code Live Server to open index.html.
4. Internet access is required because Three.js is loaded from jsDelivr.
5. Click START ENGINE & RACE. Sound starts after this click (browser audio policy).

SOUNDS INCLUDED
- Engine start and continuously changing engine rev sound
- AI car engine sound
- Countdown beeps and race start cue
- Tire squeal while steering at speed
- Collision thud / impact sound
- Win and lose result tones
- Sound ON/OFF toggle in the HUD

CONTROLS
W / Up Arrow = accelerate
S / Down Arrow = brake
A / Left Arrow = steer left
D / Right Arrow = steer right
Pause button = pause/resume
Mobile: use the on-screen controls.

RACE
- One player car vs one automatic AI car
- AI target speed: 200 km/h
- Finish line at 1000 metres (1 km)
- Checkered finish line and overhead FINISH sign

Sounds are generated using the browser's Web Audio API, so no extra sound files are required.
